# NVC 术语表（按拼音排序）

**表达四要素（OFNR）**

- **请求 (qǐngqiú) / Request** — 具体、正向、可行、当下的行动邀请，允许对方说不。区别于命令（Ch6）。
- **感受 (gǎnshòu) / Feeling** — 真实的情绪或身体感觉，能反映需要是否满足。区别于想法（Ch4）。
- **观察 (guānchá) / Observation** — 可被记录、带具体时间情境的事实。区别于评论（Ch3）。
- **需要 (xūyào) / Need** — 全人类共通的、不针对特定人的生命需要（安全、联结、自主…）。区别于策略（Ch5）。

**核心概念**

- **道德评判 (dàodé píngpàn) / Moralistic Judgment** — 用自己的标准判断他人"对/错""好/坏"，是异化沟通之首（Ch2）。
- **非暴力沟通 (fēibàolì gōutōng) / NVC** — 以联结为目的、以四要素为结构的沟通方式（Ch1）。
- **同理心 (tónglǐxīn) / Empathy** — 放下判断、接住对方观察/感受/需要/请求的倾听方式（Ch7）。
- **回避责任 (huíbì zérèn) / Denial of Responsibility** — 用"规定/你让我"切断与自己需要的联结（Ch2）。
- **强制力 (qiángzhìlì) / Coercion** — 以惩罚或奖励迫使顺从，代价是信任与自愿（Ch11）。
- **情意相通 (qíngyì xiāngtōng) / Connection** — NVC 的目的，二者需要被看见、彼此联结的状态（Ch1）。
- **自我同理 (zìwǒ tónglǐ) / Self-empathy** — 情绪触发时先向内连接需要，再向外表达（Ch8）。
- **异化的沟通方式 (yìhuà de gōutōng fāngshì) / Alienating Communication** — 道德评判、比较、回避责任、强人所难四类（Ch2）。

**感受词表（用于诊断"感受 vs 想法"）**

- **满足/愉悦类**：开心、安心、踏实、温暖、感激、欣慰、放松、兴奋
- **恐惧/不安类**：焦虑、紧张、担心、不安、害怕、恐慌
- **愤怒/挫败类**：生气、恼火、急躁、挫败、失望、委屈、愤怒
- **悲伤/失落类**：难过、伤心、失落、孤单、疲惫、无力
- **身体感觉类**：胃紧、胸口闷、肩膀僵、心跳快（可作感受入口）

**非感受词（出现在感受位 = 通常是想法）**：觉得、认为、感觉像、似乎、被忽视、被针对、不被尊重、没用、多余

**常见通用需要（needs，非策略）**：安全、确定性、可预测、自主、选择权、空间、休息、被看见、被听见、被理解、联结、归属、信任、诚实、意义、贡献、成长、公正、尊重、边界

**判断口诀**：无法确定是感受还是需要时，套用"我感到…因为我需要…"。能填进去的是感受，填不进去的是想法。
