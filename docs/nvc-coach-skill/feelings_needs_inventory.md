# 感受与需要词表（CNVC 官方清单 · 中文对照）

> 来源：Center for Nonviolent Communication (CNVC) 官方 Feelings/Needs Inventory
> （www.cnvc.org，marshall Rosenberg 编制）。仅整理事实性词表，不含原书受版权保护的正文。
> 教练用途：诊断"感受 vs 想法"、定位真实需要、生成精准改写。这两张表是 NVC 的语言基础设施。

## 使用铁律

1. **感受词表里没有的，多半不是感受**。"我觉得你不在乎"——"不在乎"是判断，不是感受。
2. **需要永远是正向、普适、不针对特定人的**。"希望你别迟到"是策略；"我需要可预测"才是需要。
3. **感受分两类**：需要被满足时的感受、需要未被满足时的感受。教练要先问"这个感受说明哪个需要被满足/没被满足"。
4. 词表是起点不是终点，鼓励用户找到更贴切的词。

## 二、需要词表（Need Words）· 9 大类

需要是生命本身的要求，不针对具体人、具体策略。教练把"我不满意 X 的行为"翻译成"我看重 Y 需要"。

| 类别 | 代表需要 |
|---|---|
| **联结 CONNECTION** | 接纳、喜爱、感激、归属、合作、沟通、亲密、社群、陪伴、慈悲、体谅、一致、同理、包容、亲密、爱、互相关怀、滋养、尊重/自尊、安全、安定、支持、被认识、被看见、被理解、信任、温暖 |
| **身心健康 PHYSICAL WELL-BEING** | 空气、食物、运动、休息/睡眠、仪容、安全、 shelter 住所、触摸、水 |
| **诚实 HONESTY** | 真实、正直、临在 |
| **玩耍 PLAY** | 喜悦、幽默 |
| **平静 PEACE** | 美、和谐、启发、秩序、安宁 |
| **自主 AUTONOMY** | 选择、自由、独立、空间、自发 |
| **意义 MEANING** | 觉察、庆祝生命、挑战、清晰、能力、意识、贡献、创造、发现、效能、成长、希望、学习、哀悼、参与、目的、自我表达、被重视、理解 |
| **完整 INTEGRITY** | 真诚、创造力、意义、自我肯定 |
| **互相依存 INTERDEPENDENCE** | 依靠、开放、彼此支持 |

> 另一常见权威版本（CNVC 简表）把需要归为 8 类：SUSTENANCE 生存 / SAFETY 安全 / EMPATHY 同理 / LOVE 爱 / CONSCIOUSNESS 觉察 / CREATIVITY 创造 / COMMUNITY 社群 / AUTONOMY 自主 / REST 休息 / MEANING 意义。两套分类本质一致，教练可交叉使用。

## 三、教练速用对照

| 用户说的（想法/策略） | 背后可能的感受 | 背后可能的需要 |
|---|---|---|
| "你从来不回消息" | 失落、着急、不安 | 被回应、被重视、可预测 |
| "你就是不负责任" | 失望、担忧 | 可靠、信任、协作 |
| "我要你今晚就改完" | 焦虑、压力 | 确定、掌控、效率（改完是策略） |
| "你凭什么批评我" | 委屈、愤怒 | 尊重、被理解、公正 |
| "随便你吧" | 无力、疏离 | 自主、被看见、参与 |

**用法**：先确认感受词是否在上表中；不在 → 追问"这个说法是感受还是你的判断？"。再确认需要是否普适；不普适（针对某个人的行为）→ 追问"你真正看重的、对自己重要的东西是什么？"。
