# NVC 教练决策表（快速参考）

## 诊断决策树

```
拿到一句话 →
  有具体时间/情境的事实吗？ ── 否 → 问题在【观察】（评论/评判）
  是 → 感受位是情绪词吗？ ── 否（是"觉得/认为"）→ 问题在【感受】（想法）
         是 → 说的是通用需要还是针对某人的策略？ ── 策略 → 问题在【需要】
                 是 → 请求具体、正向、可行、可拒绝吗？ ── 否 → 问题在【请求】
                         是 → 这是标准 NVC 表达 ✓
```

## 高频判断规则

| 看到 | 判定 | 处理方式 |
|---|---|---|
| 总是 / 从来 / 根本 / 每次都 | 观察位被评论污染 | 追问具体次数和时间 |
| 不专业 / 糟糕 / 自私 / 离谱 | 道德评判 | 翻译成"我感到…因为我需要…" |
| 真厉害啊 / 又来了（反讽） | 讽刺评判 | 同上，先同理再翻译 |
| 觉得 / 认为 / 感觉像 + 从句 | 想法冒充感受 | 换成真实情绪词 |
| 你让我… / 是你导致… | 回避责任 | 改为"我感到…，因为我需要…" |
| 尽快 / 马上 / 必须 / 不然就 | 命令 | 改为具体、可拒绝的请求 |
| 改一下 / 处理一下 / 注意一下 | 模糊请求 | 加时间、动作、可验证标准 |
| 如果…我就升级/投诉 | 威胁 | 指出这是策略不是需要，问真正需要什么 |

## 四要素验收清单

- [ ] **观察**：能指出何时何地发生了什么？能被录像吗？（不含"总是/经常"）
- [ ] **感受**：是情绪/身体感觉词，不是"觉得/认为"？
- [ ] **需要**：是通用需要（安全/联结/自主…），不是"你该怎么做"？
- [ ] **请求**：具体、正向、当下、可行、允许说不？

## 教练响应优先级

1. 先同理（接住感受与需要）——**永远第一步**
2. 再挑最关键的一个 OFNR 问题
3. 给出改写示范
4. 邀请用户用自己的话重说一遍

## 情绪处理速查

| 情绪 | 先问的需要 |
|---|---|
| 愤怒 | 被尊重？公平？边界？ |
| 焦虑 | 确定性？可预测？信息？ |
| 委屈 | 被看见？被理解？支持？ |
| 失望 | 期待？信任？承诺？ |
| 无力 | 自主？资源？选择权？ |

## 一句话记住

**"我感到〈感受〉，因为我需要〈需要〉。你愿意〈具体请求〉吗？"** —— 观察放在最前面，且不带评价。
